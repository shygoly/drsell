## 部署流程

### 前置条件

1. SSH 免密可达 `wjclaw`（`ssh wjclaw true` 应无输出退出）。
2. 本地 env 文件齐备：
   - `apps/api/.env` — `DATABASE_URL`、`SHOPIFY_API_KEY`/`SHOPIFY_API_SECRET`、`JWT_SECRET`（生产必须改掉 `drsell-dev-secret-change-me`）；
   - `apps/web/.env` — `SHOPIFY_API_KEY`、`NEXT_PUBLIC_SHOPIFY_API_KEY`；
   - 可选：`apps/storefront/.env`、`apps/ops/.env`（构建期注入 `NEXT_PUBLIC_API_URL`，缺省 `https://ops.szchada.top/api`）。
3. 本地 pnpm 可用；无需 Docker（wjclaw 不做远端构建）。

### 执行

```bash
bash scripts/deploy-mvp.sh
```

脚本按顺序做以下事情：

1. **本地构建**：packages（shared/shopify/adp/openclaw）→ `prisma generate` → api → web（standalone）→ storefront → ops。
2. **rsync 产物** 到 `wjclaw:/opt/drsell-run`（api dist + prisma/、packages dist、三个 Next standalone + static + public；同步 `apps/api/.env`、`apps/web/.env`、`apps/storefront/.env`）。
3. **nginx vhost 同步**：drsell + ops conf 推到 `/opt/webrtc-ws-proxy/conf.d/`，删除旧 `ops.drsell.szchada.top.conf`，无 ops 证书时自签。
4. **远端安装 + 迁移**：修正远端 `.env`（`PORT=5011`、`API_INTERNAL_URL=http://127.0.0.1:5011`、`postgres:5432`→`127.0.0.1`）→ `pnpm install --prod` → `prisma@6.9.0 migrate deploy` + `generate`（本次会应用 `20260902090000_audit_log`、`20260902093000_chat_stat_ai_resolved`）。
5. **pm2 重启**（delete + start + save）：

| pm2 进程 | 端口 | 说明 |
|---|---|---|
| `drsell-api` | 5011 | NestJS API |
| `drsell-storefront` | 5010 | 公开店面 |
| `drsell-web` | 5012 | Shopify embedded app |
| `drsell-ops` | 5013 | 运营控制台（新增） |

6. **nginx reload**：`docker exec webrtc-ws-proxy nginx -t && nginx -s reload`。
7. 清理旧备份 conf；（可选，需 `CF_API_TOKEN`）执行 `configure-ops-dns.sh` 保证 ops DNS 为 proxied A。

## 回滚方案

**前提认知**：`deploy-mvp.sh` 用 `rsync --delete` 直接覆盖 `wjclaw:/opt/drsell-run` 下产物，服务器上**没有历史版本**；回滚只能回退到 git 提交后重新部署。

### 应用回滚（git + 重新部署）

1. 确定回滚目标：本次发布前基线为 `baa4973`（或 `git log --oneline main` 自选）。
2. 在本地仓库回退并重新部署：

```bash
git checkout baa4973        # 或 git revert 0c4601e（生成反向提交）
bash scripts/deploy-mvp.sh
```

3. 脚本本身会 delete + start 四个 pm2 进程，等效 `pm2 restart`；如只需重启某进程：`ssh wjclaw "pm2 restart drsell-ops"`。
4. 验证：重复上文「部署即验证」六条健康检查。

### 数据库回滚

- 本次两个 migration（`20260902090000_audit_log`、`20260902093000_chat_stat_ai_resolved`）均为**纯新增**表/字段，旧代码不感知，**回滚代码无需回滚 DB**。
- 确需回滚 DB 时在 wjclaw `apps/api` 下用 `prisma migrate resolve --rolled-back <name>` 标记并手工 drop，务必先 `pg_dump` 备份。

### nginx 回滚

- vhost 由脚本覆盖至 `/opt/webrtc-ws-proxy/conf.d/`；建议部署前手工备份：
  `ssh wjclaw "cp /opt/webrtc-ws-proxy/conf.d/ops.szchada.top.conf{,.bak.$(date +%F)}"`
- 回滚：恢复备份 conf → `docker exec webrtc-ws-proxy nginx -t` → `nginx -s reload`。
- Cloudflare：`configure-ops-dns.sh` 只新增 ops 的 proxied A 记录；回滚 ops 域名时在 CF 面板删除该记录即可。
