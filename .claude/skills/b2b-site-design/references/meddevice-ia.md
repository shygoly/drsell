# 医疗器械站 IA 精髓（设计轮参考）

> 来源:调研 11 个真实站(西方巨头 Medtronic/BSC/B.Braun、原料商 JenKem/biochempeg、
> 中国出海 Mindray 等),全文见 `clients/_research/global-meddevice-sites-ia.md`。
> 用途:设计 sitecopy 时的取舍依据。**不是硬校验**——判断题,按客户素材灵活用。

## 8 条 IA 原则(直接指导 sitecopy)

1. **产品定位给双入口**:「按产品线/品类」+「按临床场景/科室/应用」并行。买家一半知道要哪类器械、
   一半只知道要解决哪个术式,单轴必漏一半人。drsell 模板的 `products`(产品线)+ `apps`(应用场景)
   已是双轴——设计时确保两轴都能定位到真实在售品,别让 apps 格子背后是空的。
2. **首页服务自助定位,别用情绪文案挡路**。正面(Mindray/B.Braun)3 秒进产品;反面(MicroPort)
   首页全是形容词、产品埋在 HCP/Patient 闸门后。hero 的 CTA 必须直指产品与询价。
3. **量化背书条紧跟 hero**:一行数据(认证数/注册国数/被引文献/产能/服役年限)胜过一段介绍。
   drsell `hero.stats` 已是此形——每个数字带 `basis` 溯源(见主 SKILL 铁律)。
4. **受众/意图分流放在转化入口,不在首页闸门**:把「你是谁 × 你要什么」做进询价(drsell 的
   distributor/hospital/OEM 三 tab + 年用量字段正是此思路,已优于绝大多数中国出海站),
   而非一进站就逼选 HCP/Patient 造成摩擦。
5. **分类命名用目标市场术语,不要机翻国内科室表**。中国出海反面:Wego 机翻出「Onychogalactidae」
   「针灸科」。做英文站时,科室/应用轴要为海外重排 + 用当地术语,扁平长列表要分组给优先级。
6. **法规市场可用性声明是成熟标志**:出海站应有「并非所有产品在所有国家注册,具体询当地代表」
   (Mindray/B.Braun)。既合规,又向专业买家传递「我们懂全球注册」。可作 footer 或 creds 区一段。
7. **信任层要「可溯源的硬件」而非形容词**:认证徽标 + 注册证**编号** + 法规市场声明 + 第三方
   文献/临床端点。drsell `creds` 的 verified 资质卡 + 询价索取证书已领先国产站(多数只堆
   「国家级/领先/创新」)。
8. **内容获客要真内容 + 分类**:技术博客/选型指南/应用案例按主题分类,而非只放「资料按需索取」占位。
   drsell `resources` 的 `planned` 机制是诚实占位,但客户能供真内容时应换成真内容。

## 优秀产品详情页的区块顺序(综合 BSC 器械 + biochempeg 原料)

面包屑 → Hero(产品名 + 规范学名/技术定语 + 价值标签) → **规格区**(器械:「直径×长度→货号」
变体矩阵;原料:CAS/牌号/纯度/分子量定义表) → 特性·收益块(每块=主张+收益+**带脚注的证据**,
避免无出处形容词) → 适应证/合规徽标 → **临床与文献证据**(具名试验+样本量+硬端点+期刊引用;
原料用 Cited Publications) → **文档下载**(IFU/DFU/MSDS/COA/注册证 PDF) → 相关产品 →
询价 CTA(数量/年用量中心)。

> **医疗特有、最常被国产站省略的是「临床/文献证据」与「IFU/COA 文档」**——买家与审评正是靠这两块决策。

## drsell 模板的缺口(设计/建站路线图,非本轮必做)

当前 drsell 是**单页 + 规格矩阵卡**,尚缺:① 产品「货号/规格变体矩阵」;② 临床证据/文献层;
③ 结构化文档下载(IFU/MSDS/COA);④ 市场可用性/法规免责模板;⑤ faceted/Quick Finder 过滤器;
⑥ resources 真内容。这些多是 catalog/sitecopy **契约的可选扩展字段**——按客户素材成熟度逐步补,
补一个就同步 render.mjs + 校验器。别一次全上,也别为不存在的素材造空板块(见主 SKILL 铁律 5)。

## 中国出海站三大硬伤 → 已由架构/校验守住

- **中文泄漏 / i18n 不干净** → 建英文站时靠 `validate-build.mjs` 的零残留 + 非目标语言字符扫描拦。
- **机翻分类词荒谬** → 靠原则 5(目标市场术语表)+ 人审。
- **JS 水合失败、首屏对机器不可读** → drsell 静态烘焙 HTML(render.mjs)+ GEO 的 `<noscript>`
  产品事实快照本身就是解药,首屏即完整、AI 可爬(见 b2b-site-build 的 GEO 段)。
